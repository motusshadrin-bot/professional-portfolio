## 📋 Описание

Это современный, адаптивный сайт-портфолио, созданный для презентации профессиональных навыков и опыта руководителя с более чем 25 годами работы на управленческих должностях.

- **Адаптивный дизайн** - отлично выглядит на всех устройствах (мобильные, планшеты, ПК)

## 🚀 Быстрый старт

### Локальный запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/motusshadrin-bot/professional-portfolio.git
cd professional-portfolio
```

2. Откройте файл `index.html` в браузере:
   - Двойной клик на файл `index.html`, или
   - Используйте Live Server расширение в VS Code

### Развёртывание на GitHub Pages

1. Перейдите в Settings репозитория
2. Найдите раздел "Pages"
3. В "Source" выберите ветку "main"
4. Сохраните изменения
5. Сайт будет доступен по адресу: `https://motusshadrin-bot.github.io/professional-portfolio/`

## 📝 Как отредактировать содержимое

### Обновить информацию в index.html:

1. **Личная информация** (секция "Обо мне")
   - Замените заглушки на вашу информацию

2. **Опыт работы** (секция "Опыт")
   - Добавьте ваши должности и даты
   - Опишите достижения на каждой должности

3. **Навыки** (секция "Навыки")
   - Обновите ключевые компетенции

4. **Достижения** (секция "Достижения")
   - Добавьте измеримые результаты

5. **Контакты** (секция "Контакты")
   - Обновите email, телефон, LinkedIn

## 🎨 Кастомизация дизайна

### Изменить цвета

В файле `styles.css` найдите основные цвета:
- `#667eea` - основной фиолетовый
- `#764ba2` - градиент фиолетовый
- `#3498db` - голубой акцент
- `#2c3e50` - тёмный фон

### Изменить шрифты

В файле `styles.css` обновите `font-family`:
```css
body {
    font-family: 'Ваш шрифт', sans-serif;
}
```

## 🔧 Расширенные настройки

### Добавить новый раздел

1. Добавьте секцию в `index.html`:
```html
<section id="new-section" class="new-section">
    <div class="container">
        <h2>Новый раздел</h2>
        <!-- Содержимое -->
    </div>
</section>
```

2. Добавьте стили в `styles.css`:
```css
.new-section {
    padding: 80px 0;
    background-color: white;
}
```

3. Добавьте ссылку в навигацию:
```html
<li><a href="#new-section">Новый раздел</a></li>
```
